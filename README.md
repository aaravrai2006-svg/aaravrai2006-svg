## 🚀 Featured Engineering Projects

### 🌾 [KisanQ — AI-Powered Smart Agriculture & Mandi Queue Infrastructure](https://github.com/aaravrai2006-svg/KisanQ)
> **Full-Stack Digital Public Platform Modernizing Agricultural Procurement and Market Intelligence**
- **Tech Stack**: `Next.js 15`, `TypeScript`, `Python`, `FastAPI`, `PostgreSQL`, `Tailwind CSS`, `Google Gemini API`
- **Core Engineering**:
  - Re-architected manual mandi paper registers and phone calls into a digitized high-concurrency procurement workflow.
  - Modelled relational data structures in PostgreSQL for farmers, procurement lots, token queues, and payments with strict transactional consistency.
  - Implemented asynchronous FastAPI backend endpoints maintaining real-time tracking across 9 consignment lifecycle stages.
  - Integrated Gemini API natural language assistant enabling farmers to query MSP rates, mandi logistics, and advisory in conversational bilingual terms.
  - Built responsive Next.js frontend with role-segregated interfaces for Farmers, Mandi Procurement Officers, and District Administrators.

### ⚙️ Self-Healing Machine System — AI Predictive Maintenance Engine
> **Industrial Telemetry Anomaly Detection & Autonomous Fault Triage**
- **Tech Stack**: `Python`, `Pandas`, `NumPy`, `Scikit-learn`, `FastAPI`, `PostgreSQL`
- **Core Engineering**:
  - Designed an end-to-end telemetry pipeline ingesting synthetic high-frequency sensor readings (vibration, heat, pressure) to forecast mechanical failure ahead of breakdown.
  - Engineered temporal features using Pandas & NumPy rolling window aggregations and variance transforms.
  - Evaluated and tuned Scikit-learn classification algorithms to optimize precision and recall, drastically minimizing false alarms in mission-critical environments.
  - Served sub-second diagnostic inferences through a lightweight FastAPI microservice with automated fault classification and PostgreSQL event auditing.
